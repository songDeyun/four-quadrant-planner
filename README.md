# 四象限计划

一个简洁的四象限任务管理工具，依据“重要／紧急”四象限组织每天的计划。

## 功能

- 四个象限分别添加计划
- 记录计划开始时间
- 勾选计划后记录完成时间
- 编辑和删除计划
- 撤销最近完成的计划
- 查看历史记录
- 按月度和年度汇总完成情况
- 导出 CSV 数据
- 导出和导入 JSON 备份
- 无网络也可以使用

## 运行

Windows 用户可以直接双击：

`四象限计划.exe`

如果系统阻止运行，也可以双击 `启动现代版.bat`。项目使用 Windows 上已有的 Edge WebView 运行现代界面，不需要登录账号。

## 数据与隐私

计划数据默认保存在当前浏览器应用的本地存储中，不会自动上传。仓库中的 `web/data.js` 不包含任何个人计划。分享个人数据前，请先使用程序的 JSON 备份功能单独保存，不要把备份文件提交到 GitHub。
