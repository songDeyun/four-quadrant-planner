# 四象限计划

一个简洁的四象限任务管理工具，依据“重要／紧急”四象限组织每天的计划。

## 功能

当前版本的每日更新和归档行为，详见 [使用说明](使用说明.md)。

- 四个象限分别添加计划
- 记录计划开始时间
- 勾选计划后记录完成时间
- 编辑和删除计划
- 撤销最近完成的计划
- 查看历史记录
- 按月度和年度汇总完成情况
- 导出 CSV 数据
- 导出和导入 JSON 备份
- 四象限下方的每日总结，实时本机保存、跨天切换空白、按日期回看
- 单个 HTML 总结记录文件，按日期累积，更新同一天的内容不重复追加
- 无网络也可以使用

## 运行

在 GitHub 点击 **Code → Download ZIP**，完整解压后，Windows 用户可以直接双击：

`四象限计划.exe`

也可以双击 `启动现代版.bat`。当前启动程序使用 Windows 上已有的 Edge 应用模式运行现代界面，不需要登录账号。请保留启动程序旁边的整个 `web` 文件夹。

## 每日总结与每日更新

在“我的计划”的四象限下方输入总结，内容实时保存到本机。按电脑本地日期分开存储，跨天后保留昨天的内容，编辑区切换至新一天；关闭或休眠时，在下次打开／唤醒时切换。没有填写的日期不会生成虚假的总结。

点击“保存总结记录”，首次选择一个专用文件 `总结记录.html`。程序按日期从新到旧生成同一个 HTML，最新一天排在最前面；同一天修改会更新对应条目，不会重复新增。

选好文件并允许写入后，程序运行期间在输入后自动更新该文件。重新打开时复用已记住的文件句柄；权限仍有效时，重开程序也会自动刷新文件；若浏览器权限过期，点击“保存总结记录”再次确认，不能仅靠更换文件格式绕过系统权限。

HTML 内容以程序内的全部总结为准，保存时重建文件，请勿选择已有的重要文档或在文件中手动编辑后期待被保留。此文件支持离线阅读，不含脚本、外部资源；正文特殊字符按文本显示。

保存仍使用“保存总结记录”，旁边的“更改保存位置”可重新选择文件或文件夹。更改时把全部日期保存到新文件，成功后切换后续自动保存的目标。取消或写入失败时继续保留原位置，原文件不会被移动或删除。

不支持固定文件写入的环境会自动退回下载方式，此时需在保存位置手动替换原文件，浏览器也可能生成新副本。提示会区分“保存成功”和“已发起下载”。程序内实时保存和跨天记录不依赖 HTML 写入权限。

JSON 备份包含计划与总结；兼容旧的仅含计划数组的备份。导入总结按日期合并，同一天保留当前非空内容；导入计划仍替换当前计划。

## 数据与隐私

计划数据默认保存在当前浏览器应用的本地存储中，不会自动上传。仓库中的 `web/data.js` 不包含任何个人计划。分享个人数据前，请先使用程序的 JSON 备份功能单独保存，不要把备份文件提交到 GitHub。

每日总结也在同一环境的本地存储中，与任务使用不同的存储键。不要清除应用的浏览器数据或随意移动 `web/index.html`；换设备或移动目录前导出备份。导出的 HTML 归档请保存在自己的文档目录中，不要提交到 GitHub。

## 开发验证

安装 Node.js 后运行 `node tests/daily.test.cjs`，验证本地日期、跨天切换、重新打开、写入失败保护、同文件更新、日期去重、HTML 内容转义和备份兼容性。测试使用内存数据，不操作个人记录。

## 编译 Windows 启动器

在项目目录运行 `powershell -File .\build.ps1`，脚本使用 Windows 的 .NET Framework C# 编译器生成 `四象限计划.exe`，不需要 Python。源码位于 `desktop/Launcher.cs`。exe 使用系统 Edge／Chrome 应用模式，仍需保留整个 `web/` 目录；它不是独立打包的浏览器运行时。
